# WashWise (SwiftUI + MVVM)

WashWise is an original iPhone app concept for scanning clothing care labels and explaining laundry instructions in plain language.

## Core Features
- SwiftUI + MVVM architecture
- Camera/photo import flow for label scans
- OCR-ready pipeline (Vision) with symbol fallback parser
- Care explanation for wash, dry, bleach, iron, and dry clean
- Garment library with photo, fabric, notes, and wash history
- Stain guide with fabric-safe suggestions
- Reminder notifications for laundry/care tasks
- SwiftData local persistence
- StoreKit 2 monetization (free + premium tiers)
- Sample garments and SwiftUI previews
